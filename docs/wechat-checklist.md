# 微信真机检查单(一页,发版前过)

安卓 X5 内核与 iOS WKWebView 各过一遍。任何一项不过,不发版。

## 安卓(微信内置浏览器 / X5)

- [ ] 微信内打开速度:首屏可见内容 ≤ 2 秒(境内网络)
- [ ] 首屏传输 ≤ 300KB(Chrome DevTools 远程调试或代理抓包确认)
- [ ] 长按创始人二维码可识别加好友
- [ ] 选商品 → 复制订单:剪贴板内容正确(期号、ref、商品、合计、锁价日)
- [ ] 剪贴板复制失败时:出现可长按全选的降级文本框 + 「长按复制」提示
- [ ] 连点「复制订单」不产生重复归因事件(同类事件每次加载只报一次)
- [ ] 「复制本期链接」透传当前 ref(粘贴出的链接带 ?ref=)
- [ ] 存档页链接携带 ref;返回本期后 ref 仍在

## iOS(微信内置浏览器 / WKWebView)

- [ ] 上述所有条目重过一遍
- [ ] 底部「复制订单」栏不被 iPhone 底部安全区遮挡
- [ ] 转发链接给另一个微信号:打开显示 title 正常(无卡片是预期,认证服务号拿不到)

## 数据侧(发版后半小时内)

- [ ] D1 events 表有本次真机测试的 open / copy 事件,ref 正确
- [ ] 用未发放的乱码 ref 打开一次,确认事件落库且 ref 被降级为 direct(不归到任何码名下)
